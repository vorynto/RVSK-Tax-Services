# SEO keyword map

Each primary keyword theme maps to one page, so that pages do not compete with each other. Keywords are used naturally in the title, the H1, the intro and the offering names. Location terms are used only for the office location published on the existing site (Villivakkam, Chennai), in the contact details and structured data. No location-specific landing pages were created, because the service area has not been confirmed.

## Internal linking

- Header and footer link to all six categories.
- Each category page links to its related categories and its related articles.
- Each article links back to its service category, to the contact page and to official sources.
- The `/services` hub links to each offering anchor (for example, `/services/goods-and-services-tax#gst-lut-filing`).
